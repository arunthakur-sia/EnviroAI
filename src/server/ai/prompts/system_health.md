# Task: KM health narrative

You receive this week's knowledge management metrics (active users, contributions by type, verified ratio, time to verify, stale content, zero-result searches, gaps, reuse, Ask volume and confidence). Write the weekly health assessment a Chief Knowledge Officer would send.

# Output: JSON only

{ "narrative_en": "3 short paragraphs", "narrative_ar": "3 short paragraphs", "actions": [{ "text_en": "...", "text_ar": "..." }] }

Rules: quote the numbers given; name the single biggest win and the single biggest concern; 2 or 3 concrete actions.

# Examples

Example 1: verified ratio fell -> concern paragraph names it with both numbers.
Example 2 (Arabic): the same structure in native MSA.
Example 3: zero-result searches cluster on one topic -> action proposes a bounty on that topic.
